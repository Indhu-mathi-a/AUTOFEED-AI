# 🚀 AutoFeed AI
### **Intelligent Feedback & Personality Analysis System**

AutoFeed AI is a state-of-the-art platform that transforms how feedback is collected and interpreted. By leveraging role-based logic and smart trait mapping, it converts raw data into deep, actionable personality insights.

[![Deployment - Vercel](https://img.shields.io/badge/Deployment-Vercel-black?style=for-the-badge&logo=vercel)](https://autofeed-ai.vercel.app)
[![Deployment - Hugging Face](https://img.shields.io/badge/Deployment-Hugging%20Face-yellow?style=for-the-badge&logo=huggingface)](https://huggingface.co/spaces/IndhumathiA/autofeed-ai)

---

## ⚠️ The Problem
Traditional feedback tools are often:
- **Too Generic**: Using the same questions for everyone regardless of their role.
- **Hard to Interpret**: Providing raw scores without explaining what they mean for growth.
- **Visually Dull**: Using dated interfaces that result in low engagement from respondents.

## ✅ The Solution
AutoFeed AI bridges this gap by:
1. **Role-Driven Forms**: Dynamically selecting questions based on the subject's role (Lead, Student, Peer, etc.).
2. **AI-Mapped Traits**: Grouping responses into core behavioral clusters (Leadership, EQ, etc.).
3. **Strategy-First Output**: Generating professional reports with automated growth suggestions.
4. **Premium Experience**: Using a modern Glassmorphic design system that feels premium and interactive.

---

## ✨ Key Features
- 🧠 **Smart Generation**: Dynamically pull from a bank of 400+ targeted questions.
- 📊 **Real-Time Analytics**: Live radar charts and consensus tracking powered by Firebase.
- 💎 **Glassmorphism UI**: High-end dark theme with fluid animations and responsive layout.
- 🔗 **Instant Sharing**: Shareable public links for anonymous 360-degree feedback.
- 📝 **Pro Reports**: Exportable AI-analyzed persona reports with growth recommendations.
- 📱 **Fully Responsive**: Optimized for every device: Mobile, Tablet, and Desktop.

---

## 🛠️ The Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Modern CSS3.
- **Database**: Firebase Firestore (NoSQL Real-time DB).
- **Visualization**: Chart.js for data mapping and radar charts.
- **Backend (HF)**: Python Flask (serving static assets).
- **Deployment**: Vercel & Hugging Face Spaces.

## 🚀 Getting Started

### Prerequisites
- A modern web browser.
- (Optional) A Firebase project for your own database tracking.

### Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Indhu-mathi-a/AUTOFEED-AI.git
   ```
2. Navigate to the project folder:
   ```bash
   cd AUTOFEED-AI
   ```
3. Open `index.html` in your browser or run a local server:
   ```bash
   npx serve .
   ```
